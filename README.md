組別:12
專題題目:21點
組員:陳柏鈞、張家碩、黃博昇
遊戲玩法:一位玩家與電腦輪流抽牌，玩家可以選擇抽或不抽，只要不超過21點就可以一直抽牌，選擇不抽牌的話，會去計算兩方的點數，如果點數大於電腦則獲勝，反之電腦獲勝
