組別號碼 : 12
系級班級 : 資工 2A
成員資訊 : 黃博昇、陳柏鈞、張家碩
小專題題目 : 21點
遊戲規則 :
遊戲玩法為，一位玩家與電腦輪流抽牌，玩家可以選擇抽或不抽，只要不超過21點就可以一直抽牌，選擇不抽牌的話，會去計算兩方的點數，如果點數大於電腦則獲勝，反之電腦獲勝。。
程式介紹 :
遊戲用牌為一副牌，去除兩張鬼牌。每人發派1張牌作為手牌。玩家須透過補牌使自身牌組加總靠近十點半，並與莊家的牌組進行大小比較。
遊戲人數設定為2人，一名電腦（PC）以及一名玩家（Player）。
玩家下注，下注完後每人發一張牌，玩家與莊家比大小，輸牌便損失注金，贏牌可以向莊家索取規定倍數的獎金。
牌面A=1點，2~9即為牌面點數，J、Q、K都算10點。
基本玩法 :
*發牌階段:
玩家和莊家各抽兩張牌。
顯示玩家的手牌和莊家的明牌。
玩家回合:
玩家可以選擇「抽牌」(hit) 或「停牌」(stand)。
抽牌: 玩家再從牌堆中抽一張牌，然後顯示新的手牌。如果手牌總值超過 21，則顯示「爆掉」的訊息，遊戲結束。,
停牌: 玩家停止抽牌，進入莊家的回合。
莊家回合:
莊家根據規則行動：如果手牌總值小於 17，則必須抽牌，直到手牌總值達到 17 或以上。,
顯示莊家的最終手牌。
勝負判斷:
比較玩家和莊家的手牌總值：
如果莊家的手牌總值超過 21，則玩家勝利。
如果玩家的手牌總值超過莊家且不爆掉，則玩家勝利。
如果兩者手牌總值相同，則為平手。
否則，莊家勝利。
遊戲示例
發牌:
玩家抽到 8 和 5（總值 13），莊家抽到 10 和暗牌（明牌是 10）。
玩家選擇:
玩家選擇抽牌，抽到 7（總值 20）。
玩家選擇停牌。
莊家行動:
莊家明牌是 10，暗牌是 6（總值 16），所以莊家再抽一張牌，抽到 9（總值 25，爆掉）。
結果:
玩家勝利，因為莊家爆掉
